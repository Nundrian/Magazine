# Proposed GitHub public beta

This document records the beta.5 publication boundaries. The repository is
[Nundrian/Magazine](https://github.com/Nundrian/Magazine).

The beta.5 source and native Function package are available as a public
prototype. The downloadable files and their checksums are held under `downloads/`
in the repository, pending any later GitHub Releases migration:

- `Magazine-0.1.0-beta.5-FunctionOnly.zip`: accepted native installation option.
- `magazine-function.json`: direct import of the same native Function.
- `Magazine-0.1.0-beta.5.zip`: matching full source and optional review recipe.
- `magazine_ef.py`: reviewable Function source.
- `SHA256SUMS.txt`: checksums of those assets.

Link the short install guide and state: Open WebUI 0.11.3 is the tested host;
native installation uses a bookmark and has no permanent sidebar button;
inherited host risks are disclosed; the sidebar image remains on distribution
HOLD. The source recipe is not an approved binary distribution. Publish no
Docker image and perform no production deployment.

Do not upload this complete review directory. Private backups, accounts, chat
evidence, image tarballs, caches and temporary scripts are outside both profiles.
Keep the immutable beta.3 reference separate.

Checksums are recorded in `downloads/SHA256SUMS.txt`. New builds require new
fingerprints and acceptance accounting. Do not silently replace already
published, immutable candidate archives.
