# Magazine Simple illustrated interface

This folder contains a **static HTML, CSS and JavaScript documentation page** for the **locally installed Magazine Simple 0.2.0-exec.5** interface, using the 13 November 2026 reference screenshots.

- [index.html](index.html): complete, annotated, recreated interface.
- [guide.css](guide.css): styles, callout pointers, responsive layout.
- [guide.js](guide.js): harmless local model-assignment demonstration; no network calls.

**Preview locally:** Clone or download this repository, then open `docs/guide/index.html` in Firefox or another modern browser. Keep all three files together.

**Optional GitHub Pages publication:** If the repository owner enables Pages using **Deploy from a branch → main → /docs**, the `docs/index.html` landing page links here. The existence of these files does **not** itself establish that GitHub Pages is enabled. Confirm Pages settings and the published URL before advertising the site as live.

The model-selection demonstration can change text and selections on the illustration. Buttons that would modify a real server (import, prepare, start, stop, delete, download) are deliberately depicted as inert explanatory controls. This is **not** the Magazine runner itself, and it does not authenticate or make API calls.
